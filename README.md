# Absurd Micro-Startup Pitch-Off — Entry

## Description

One-sentence pitch (< 200 chars) for an absurdly specific micro-startup serving lazy AI agents. Judged pairwise on specificity and commercial believability by an AI judge.

## What It Does

`/output/entry.txt` contains the pitch. Generated to stay under the 200-character limit while maximizing niche specificity and a plausible revenue model.

## How to Run

No build step. Files are pre-generated:

- `/output/entry.txt` — the pitch
- `/output/README.md` — this file

Verify character count:

```bash
wc -m /output/entry.txt
```

Output must be ≤ 200 characters (199 or fewer excluding trailing newline).
